# 甜點捏捏樂

一個可以自由搭配烘焙材料、創作甜點，再把成品加入收藏館捏玩的互動網頁。

## 開始遊玩

直接開啟遊玩頁面即可開始：

https://41154b027.github.io/sweet-squishy-studio/

要查看作品原始檔，請前往 GitHub repository：

https://github.com/41154b027/sweet-squishy-studio

## 遊戲內容

- 用滑鼠或觸控按壓、拉扯甜點捏捏。
- 在我的工作室探索食材，選粉類作為基底並自由混搭。
- 遇到不合適的組合時會收到提示。
- 製作完成的甜點會加入收藏館，可以繼續捏玩。
- 按壓次數、收藏、學堂進度和每日籤詩會保存在瀏覽器。

## 專題

本作品以單一 HTML 頁面製作，使用 CSS 動畫與 JavaScript 呈現互動。玩家不必登入即可遊玩，遊戲進度會自動保存在目前使用的瀏覽器中。更換瀏覽器或裝置前，請先下載存檔備份，再匯入進度。

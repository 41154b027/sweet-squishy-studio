# 甜點捏捏樂

一個可以自由搭配烘焙材料、創作甜點，再把成品加入收藏館捏玩的互動網頁。

## 開始遊玩

直接開啟 `index.html` 即可體驗。若要分享給同學，可在 GitHub 建立公開 repository，並到 **Settings → Pages** 將部署來源設為 `main` 分支的根目錄。

## 遊戲內容

- 用滑鼠或觸控按壓、拉扯甜點捏捏。
- 在我的工作室探索食材，選粉類作為基底並自由混搭。
- 遇到不合適的組合時會收到提示。
- 製作完成的甜點會加入收藏館，可以繼續捏玩。
- 按壓次數、收藏、學堂進度和每日籤詩會保存在瀏覽器。

## 專題

這個作品以單一 HTML 頁面製作，包含 CSS 動畫、JavaScript 互動和瀏覽器端進度保存。遊戲存檔只在目前瀏覽器與網站來源中保存；清除瀏覽資料後可能需要還原備份。
